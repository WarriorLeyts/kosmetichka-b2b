# Тесты для сотрудников

Сотрудники проходят тесты на **https://test.kosmetichka-opt.ru** (на основном домене тот же раздел — `/academy`).
Вход — рабочим логином и паролем (таблица `User`, те же учётки, что в панели сотрудника и у сборщиков).
Администраторы и менеджеры дополнительно видят «Результаты сотрудников».

## Как добавить или изменить тест

**Проще всего — в браузере:** HR и администратор открывают «Редактор тестов» (`/academy/manage`).
Там создаются тесты и вопросы; к вопросу можно привязать товар по коду номенклатуры 1С (например `ЦБ000012380`),
штрихкоду или названию — фото подтянется из каталога сайта.

Ниже — загрузка из файлов (для больших тестов из Word). **Внимание:** импорт с тем же `slug`
перезапишет тест, отредактированный в браузере.

1. Положите файл `*.json` в эту папку (один файл — один тест), образец — `00-primer.json`.
2. Проверьте без записи в базу: `npm run import:tests -- --check`
3. Загрузите (на сервере, из папки сайта): `npm run import:tests`

Тест находится по `slug`: если такой уже есть, он обновляется, а его вопросы заменяются целиком.
Уже сохранённые результаты сотрудников при этом не теряются.

## Формат

| Поле | Обязательно | По умолчанию | Что это |
|---|---|---|---|
| `slug` | да | — | адрес теста, латиница/цифры/дефис: `kassa-basics` → `/academy/t/kassa-basics` |
| `title` | да | — | название |
| `description` | нет | — | пара предложений перед первым вопросом |
| `passScore` | нет | `80` | проходной балл, % правильных ответов |
| `timeLimitMin` | нет | без лимита | минут на тест; по истечении ответы отправляются автоматически |
| `showAnswers` | нет | `true` | не используется: сотрудник после сдачи видит только итог, разбор с ответами — только HR и админ в «Результатах сотрудников» |
| `shuffle` | нет | `true` | перемешивать вопросы и варианты |
| `isPublished` | нет | `true` | `false` — тест скрыт от сотрудников |
| `sortOrder` | нет | `0` | порядок в списке (меньше — выше) |
| `questions` | да | — | вопросы, см. ниже |

Вопрос: `text`, `options` (минимум 2), необязательное `explanation` — пояснение в разборе.
Необязательное `productId` — номер товара в каталоге сайта (как в адресе `/product/<номер>`): в вопросе покажется
его фото. Фото берётся с сайта при показе, так что после обновления в 1С оно обновится и в тесте.
Правильные ответы отмечаются одним из двух способов:

```json
{ "text": "Вопрос", "options": [{ "text": "Верно", "correct": true }, { "text": "Неверно" }] }
{ "text": "Вопрос", "options": ["Верно", "Неверно", "Тоже верно"], "correct": [1, 3] }
```

Если правильных вариантов несколько, сотрудник видит пометку «несколько правильных ответов».
Вопрос засчитывается, только когда отмечены все правильные варианты и ни одного лишнего.
