# Оформление скидочной карты

Карта «Косметичка» стоит 990 ₽. Розничный клиент без скидочной карты может добавить её в корзину отдельно или с товарами. Форма запрашивает ФИО и дату рождения, телефон берётся из профиля. Пока карта в корзине, товары получают скидочную цену. Удаление карты возвращает обычный расчёт. Постоянный статус клиента покупка в корзине не меняет.

Сервер находит реальный товар по названию «Карта Косметичка» без учёта регистра. При необходимости `LOYALTY_CARD_PRODUCT_GUID` явно задаёт GUID номенклатуры. Если товар исключён из каталожного обмена, форма читает его из 1С по OData и сохраняет локально скрытым от обычного каталога. Новая номенклатура в 1С не создаётся. При отсутствии или неоднозначности товара оформление не разрешается.

Цена карты фиксирована на сервере, количество — одна, бонусы/промокоды на её стоимость не применяются. В комментарий заказа (и далее документа 1С) добавляются ФИО, дата рождения, телефон из профиля и инструкция оформить карту на кассе.

Автопривязка: worker в `instrumentation.ts` раз в минуту читает неделённых контрагентов и дисконтные карты через существующие `ODATA_*`. Телефоны нормализуются до `+7XXXXXXXXXX`, разделители удаляются. Сравнивается весь номер, а не последние цифры. При нескольких аккаунтах на один нормализованный телефон, нескольких подходящих скидочных картах или карте, уже привязанной к другому аккаунту, автоматическая привязка пропускается. Из единственной бонусной карты и единственной скидочной выбирается скидочная. Цена определяется прежними правилами: префикс 900 либо группа «Максма Скидка».

Открытый профиль обновляет карту каждые 30 секунд, данные клиента — также раз в минуту в активном приложении. Фактическая задержка зависит от ответа 1С. Если MAXMA ещё не знает карту из 1С, профиль показывает саму карту с недоступным балансом, без выдуманного количества бонусов. Сбой 1С сохраняет существующую привязку.

Схема базы не меняется. Выкладка: сначала backend `kosmetichka-b2b`, затем `kosmetichka-app`. Проверки API не оформляют реальные карты в 1С и не создают заказы на рабочем сервере.
