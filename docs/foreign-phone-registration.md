# Регистрация с иностранным номером

«Иностранный номер» переключает подтверждение с SMS на email. Номер контакта обязателен в международном формате с `+`, 7–15 цифр; номера `+7` используют существующий SMS-сценарий. Международный номер сохраняется с кодом страны для WhatsApp, без преобразования в российский.

POST `/api/auth/email/send` принимает `{ email, phone }`, отправляет шестизначный код на нормализованный email и возвращает `{ success, challengeId }`. Письмо отправляется через существующую конфигурацию `EMAIL_*`. Код действует 10 минут, ограничен пятью попытками, хранится как HMAC с секретом приложения и связан с email и телефоном. Отправка ограничена по адресу, IP, интервалу и всему сайту.

Регистрация принимает `foreignPhone: true`, `emailChallengeId`, `emailCode` вместе с обычными полями и CAPTCHA. SMS в этом сценарии не используется. Смена email/телефона требует нового кода. Код расходуется однократно. Розница получает доступ сразу, опт проходит существующее подтверждение администратором.

`Customer.phoneUnverified=true` обозначает контактный телефон, владение которым не подтверждалось. Такие аккаунты не участвуют в автоматическом поиске/замене карт MAXMA; при регистрации не сопоставляются с контрагентом 1С по телефону. Ручная привязка карты по прежнему требует подтверждения MAXMA. Подтверждённая по SMS смена телефона снимает флаг, изменение телефона администратором устанавливает его. Для прежних аккаунтов текущий порядок сохранён.

Перед backend-релизом применить `prisma/manual/2026-11-16-foreign-phone-registration.sql` (добавляет поле и отдельную таблицу кодов, не удаляет данные). Затем опубликовать браузерные сборки клиентского приложения и Team.
