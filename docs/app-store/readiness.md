# Подготовка клиентской «Косметички» к App Store

Проверка: 18 ноября 2026, Москва. Это технический аудит исходников и воспроизводимых сценариев, а не одобрение Apple и не подтверждение всех юридических оснований обработки.

## Исправления в этой работе

- Самостоятельное удаление аккаунта дополнительно очищает серверную корзину, избранное, поля оптовой заявки / анкеты, материалы подтверждения торговли и их файлы; отключает рекламу и доступ, обновляет время отзыва сессий. Работает через общий API сайта и приложений. Заказы и их переписка сохраняются; экран больше не обещает их обезличивание.
- Старый токен загрузки оптовых доказательств отклоняется для удалённого / заблокированного аккаунта.
- Общая поддержка без регистрации: kosmetichka.upl@gmail.com, +7 938 905-94-94. Ссылка для App Store: https://kosmetichka-opt.ru/contacts.
- Контакты, политика и соглашение доступны в приложении даже при скрытии пунктов меню в CMS. Контакты читаются из таблиц страницы CMS с резервным значением в приложении.
- Ошибка запуска камеры показывается пользователю; распознавание штрихкода имеет альтернативу — текстовый поиск. Отказ в уведомлениях не блокирует работу.
- Невалидный JSON / HTML с HTTP 200 становится ошибкой запроса, а не null, который ломает экран. Изменение действует в клиентском и менеджерском приложениях.
- Разрешения камеры, фото и микрофона описывают фактические функции. Проверяется итоговый Info.plist, а не только app.json.
- IOS_DISTRIBUTION=app-store: APNs production, регистрация iOS push-токена при согласии, отдельный runtime 5-app-store, Expo OTA выключен. Подписанный iOS workflow выбирает этот режим при наличии Apple signing credentials. По умолчанию остаётся sideload с runtime 5 и совместимыми OTA. Переход с runtime 4 требует установки новой IPA / APK, поскольку изменены нативные разрешения и подпись. Плагин sideload удаляет APNs после остальных плагинов; ранее он выполнялся раньше добавления APNs.

## Уже реализовано, но требует проверки в финальной подписанной сборке

- Публичный каталог и поиск без авторизации; регистрация по телефону с SMS, для иностранных номеров — подтверждение e-mail. Настоящие SMS не отправлялись в ходе аудита.
- Вход, восстановление пароля, подтверждение удаления текущим паролем, прекращение сессий заблокированного аккаунта. Реальные клиентские аккаунты в ходе аудита не удалялись.
- Корзина / избранное сохраняются локально; чтение API ограничено 15 секундами и показывает ошибку. Checkout блокирует повторное нажатие и сохраняет requestId для повторного запроса. Серверная дедупликация только в памяти процесса на 10 минут: не гарантирует отсутствие дубля после перезапуска процесса или длительного перерыва. Запись намеренно не прерывается общим таймером; бесконечно зависшее соединение при записи — оставшийся сценарий для теста на устройстве.
- Оформление заказа физических товаров с согласованием оплаты менеджером; StoreKit / IAP для косметики не требуется. Реальные заказы не создавались.
- Чат с фото, видео, документами и голосом; запрашиваемые разрешения связаны с этими действиями. Нет запроса геолокации / контактов для покупки; в проверенных зависимостях не найден рекламный SDK / ATT-интеграция.

## Что пока нельзя отметить как готовое

1. Apple Developer Program и App Store Connect: владелец, продавец, страны, условия договоров, сертификаты / профили, APNs-ключ. Без них не проверены подписанная магазинная сборка и доставка push на iPhone. Код поддержки APNs не заменяет настройку ключей Expo / Apple.
2. Черновик расширенной политики: docs/app-store/privacy-policy-draft.md. Перед публикацией определить реальные сроки хранения адресов / переписки / резервных копий, процесс удаления сведений в 1С, Bitrix24 и MAXMA, основания передачи и размещение данных у внешних сервисов. Не заявлять «все данные мгновенно удаляются» или «все данные только в РФ» без подтверждения всех потоков. В этой работе обновлён только черновик CMS, опубликованный текст не заменяется автоматически.
3. App Privacy в App Store Connect: сверить таблицу ниже с окончательным бинарником, SDK PrivacyInfo.xcprivacy и фактически включёнными серверными сервисами. Требуемые причины использования системных API должны быть подтверждены собранным Xcode privacy report.
4. Тестовый аккаунт для App Review: отдельный от реальных клиентов, доступ ко всем заявленным функциям без ожидания ручного подтверждения. Не создавать секретный обход авторизации и не менять реальные роли клиентов ради ревью.
5. Проверка на настоящем iPhone / TestFlight по сценариям ниже. Симулятор и браузер не подтверждают работу камеры, микрофона, APNs, системной подписи и всех разрешений iOS.
6. Иконки / скриншоты / возрастной рейтинг / support URL / privacy URL / сведения о шифровании / описание — заполнить для фактического релиза. Apple рассматривает приложение самостоятельно; совпадение дизайна с сайтом допустимо, но React Native сам по себе не гарантирует соответствие 4.2.

## Проверка на iPhone перед отправкой

- Чистая установка: открыть каталог без регистрации, поиск, фильтры, карточка и избранное; проверить светлую / тёмную тему и увеличенный текст.
- Регистрация / SMS или e-mail, неверный код, восстановление пароля, вход / выход; отклонение камеры, микрофона, фото и уведомлений не должно блокировать основные функции.
- Поддержка / политика доступны до регистрации. Проверить mailto / tel и доступ к документам без cookie входа.
- Тестовый заказ: сеть отключена до отправки и потеря связи после нажатия; корзина не теряется, повторная попытка в пределах дедупликации не создаёт второй заказ. Проверить появление заказа на другом устройстве и после перезапуска сервера отдельно.
- APNs: согласие / отказ, foreground / background / холодный запуск, переход в нужный заказ; при выходе отвязать устройство.
- Камера: разрешить / запретить / отозвать в Настройках, неверный штрихкод; фото / видео / голос, отмена выбора, сеть во время загрузки.
- Удаление только специально созданного тестового аккаунта: неверный пароль, правильный пароль, отсутствие доступа со второго устройства; очистка корзины / избранного / оптовых доказательств и сохранение законно необходимых заказов согласно опубликованной политике.
