# Ассортимент по фото

В CMS в карточке товара, блок «Ассортимент по фото»: включить «Ассортимент — выбор по фото», отметить фото по одному или кнопкой «Отметить все фото», задать названия, порядок и доступность. «Снять выделение» очищает выбранные фото. Изменения применяются кнопкой «Сохранить ассортимент». Аналогичный блок есть в карточке товара Team. Обычная галерея остаётся независимой от вариантов.

Цена, штрихкод и остаток едины для всех видов. Минимальный заказ проверяется по сумме выбранных видов. Клиент видит смену фото каждые 3 секунды (кроме режима уменьшения движения), отметку «Ассортимент» и «Выбрать виды». В корзине и заказе сохраняются отдельные строки с названием и фото вида. Наличие видов подтверждается при сборке штатными действиями заказа; замены согласовываются с клиентом.

В 1С строки вариантов объединяются по номенклатуре и цене внутри каждого складского документа; суммы скидок сохраняются. Расшифровка видов и количеств добавляется в комментарий. История заказов хранит снимки названий и фотографий, переименование варианта её не меняет. ID вариантов сохраняются при переименовании/изменении порядка; удаление и повторное создание фото-варианта требует нового выбора в старой корзине.

Перед выкладкой применить prisma/manual/2026-11-16-assortment.sql. Существующие варианты включаются как ассортимент. Новые товары по умолчанию обычные; 1С не управляет настройкой ассортимента.
